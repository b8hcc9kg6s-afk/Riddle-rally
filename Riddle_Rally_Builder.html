100% Free Lifetime Hosting

You do not need to spend any money! You can publish this interactive website directly using free cloud hosting from GitHub Pages or Vercel.

Why it's completely free: Both GitHub Pages and Vercel offer generous free tiers for static front-end HTML/JS web apps with zero monthly costs or credit cards needed.
Share with class: Once hosted, students can open the web link on tablets, smartphones, or classroom laptops without installing any apps!

How to Host on GitHub Pages or Vercel

  1. Create a Free GitHub Account: Go to github.com and sign up for free.
  2. Save this Website File: Save this entire application code into a file named index.html on your computer.
  3. Create a Repository: Click the + icon on GitHub and select New Repository. Name it riddle-rally and keep it Public.
  4. Upload index.html: Click "uploading an existing file", drag your index.html, and click Commit changes.
  5. Enable Pages: Go to Settings → Pages. Under Build and deployment / Branch, choose main (or master) and click Save.
  6. Done! In 1-2 minutes, GitHub will give you a live free URL like https://yourusername.github.io/riddle-rally/ to share with your class!
  1. Create a Free Vercel Account: Sign up at vercel.com using your email or GitHub account.
  2. Install Vercel CLI (Optional) or Drag & Drop: You can simply link your GitHub repository (created in Option A) directly inside Vercel with 1 click.
  3. Instant Deployment: Vercel automatically detects the HTML page and deploys it in under 10 seconds.
  4. Custom Domain / Free Link: Vercel gives you a super-fast free link ending in .vercel.app.
